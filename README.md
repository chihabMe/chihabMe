## 🚀 Featured Project

### 🧠 Permission-Safe AI Knowledge Graph

A client-oriented AI knowledge system that combines organizational data, graph retrieval, authorization, and LLMs.

**Architecture**

`Google Drive → Django → PostgreSQL / Neo4j → SpiceDB → Open WebUI → LLM`

Built with:

- Django & Django REST Framework
- PostgreSQL
- Neo4j
- SpiceDB
- Redis
- Celery
- Open WebUI
- OpenRouter
- Docker Compose
- Traefik
- Linux / Ubuntu

The system enforces document permissions **before information reaches the retrieval or LLM layer**, preserving source-level access control.

🌐 Live demo: https://graph.drakebuilds.biz/
